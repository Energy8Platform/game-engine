# Максимальный выигрыш (максвин)

## Что такое Максимальный выигрыш платформы?

**Максимальный выигрыш (максвин)** — это ограничение на максимальную сумму выигрыша, которую игрок может получить в рамках одного раунда.

## Назначение

Функционал ограничения максимального выигрыша (Max Win) в одном игровом раунде служит для защиты партнеров (операторов) от крупных выплат.

Функционал позволяет администратору Artube задавать лимит выигрыша на уровне интеграции (в евро по умолчанию), с автоматической конвертацией в валюту игрока. При достижении лимита выигрыш игрока обрезается, игроку показывается соответствующее уведомление.

При создании сессии Max Win будет конвертирован, если таковой имеется, в валюту сессии и отдавать эту информацию в поле `platform_max_win` для дальнейшего потребления игрой.

Также будет добавлен верхнеуровневый контроль максимального выигрыша, который проверяет каждый выплачиваемый вин игроку и в случае превышения лимита снижать выплату. Такая модификация записывается в БД раундов, отображена клиенту посредством спец флагов/поле.

## Фронтенд

- Анимации и стандартные игровые анонсеры не изменяются. Анимации линий, множителей, бонусов, фриспинов и стандартные анонсеры выигрыша (Raw Win / Total Win по математике) должны отрабатываться полностью и без прерываний.
- В случае достижения лимита Max Win, после завершения стандартных анонсеров с Raw win отображается универсальное модальное окно с текстом о достижении лимита Max Win и итоговой фактически зачисленной суммой Win.
- Модальное окно является блокирующим. При достижении Max Win в игре отображается блокирующее универсальное модальное окно, требующее явного подтверждения игроком.
- Фактически зачисленная сумма с учетом лимита Max Win отображается явно.
- Все значения выигрыша в модальном окне отображаются в валюте игровой сессии игрока.
- В модальном окне должен быть текст, объясняющий причину ограничения выигрыша, например: “Вы достигли максимального выигрыша для этого раунда. Ваш выигрыш был ограничен до [фактическая сумма выигрыша с учетом Max Win]”.

## Бэкенд

- Математика игры не изменяется. Расчёт линий, множителей, бонусных механик и фриспинов выполняется без учёта Max Win.

> Осторожно
>
> На данный момент функционал Max Win доступен только для администраторов Artube. Пользователи Artube Hub не имеют возможности самостоятельно настраивать Max Win.
