# Обзор геймификации

## Что это такое?

**Геймификация** — это сервисный слой, предназначенный для повышения вовлеченности (Retention) пользователей в ваши игры. Он работает как независимый виджет, накладываемый поверх игрового интерфейса.

Сервис берет на себя весь жизненный цикл промо-активностей:

- Запуск турниров с таблицами лидеров (Leaderboards).
- Проведение розыгрышей призов (Prize Drops).
- Автоматическое распределение наград в различных валютах.

## Как это работает?

Вам не нужно реализовывать логику турниров внутри игры.

1. **Инициализация сессии** В ответе на запрос информации о сессии через Games API приходит специальный `gamification_token`.
2. **Передача на клиент** Бэкенд игры передает этот токен на фронтенд (клиентскую часть игры).
3. **Запуск виджета** Клиент игры инициализирует виджет, используя полученный токен.
4. **Оверлей** Поверх игры отображается UI геймификации. Игрок видит свой прогресс, места в турнирах и уведомления о выигрышах, не покидая игру.

> Заметка
>
> Мы не гарантируем фактическое использование геймификации оператором. Эта возможность является дополнительной, расширяет общий функционал, но не представляет собой обязательное требование с нашей стороны.
