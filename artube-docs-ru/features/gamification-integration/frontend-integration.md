# Интеграция виджета геймификации

> Совет
>
> Эта страница описывает техническую реализацию на стороне клиента. Общую информацию о сервисе см. в разделе [Обзор геймификации](gamification-overview.md).

## Предварительные требования

Для работы виджета необходим `gamificationToken`. Он должен прийти в ответе на запрос сессии от вашего игрового сервера (который, в свою очередь, получает его от API платформы).

Если токен отсутствует или равен `null`, инициализировать виджет **не нужно**.

## Этапы интеграции

1. **Получение токена**

   Дождаться ответа на запрос сессии, содержащего поле `gamificationToken`.
2. **Загрузка скрипта виджета**

   Загрузить скрипт с адреса `https://assets.gamification-platform.com/widget-launcher.js` асинхронно в `<head>` документа. Вы можете загрузить скрипт до получения токена, если его влияние на загрузку вашей игры вас не беспокоит.
3. **Инициализация виджета**

   Вызвать метод `window.MyWidgetLauncher.init()` с обязательными параметрами.
4. **Подписка на изменение размера окна**

   Настроить обработчики для обновления позиции виджета при смене ориентации или размера окна.

## Параметры инициализации

| Параметр | Тип | Описание |
| --- | --- | --- |
| `token` | `string` | Токен из ответа сессии (`gamificationToken`) |
| `sessionId` | `string` | Идентификатор игровой сессии из URL страницы клиента |
| `lang` | `string` | Код языка (`EN`, `RU` и т.д.) |
| `position` | `WagercraftPosition` | Позиция виджета на экране |
| `env` | `string` | Окружение: `demo`, `prod` |

## Позиционирование

### WagercraftPosition

Объект позиционирования с четырьмя опциональными полями:

```plaintext
WagercraftPosition {
  top?: string     // CSS-значение отступа сверху
  right?: string   // CSS-значение отступа справа
  bottom?: string  // CSS-значение отступа снизу
  left?: string    // CSS-значение отступа слева
}
```

| Поле | Тип | Описание | Пример |
| --- | --- | --- | --- |
| `top` | `string` | Отступ от верхнего края экрана | `"20px"`, `"5vh"` |
| `right` | `string` | Отступ от правого края экрана | `"10px"`, `"2%"` |
| `bottom` | `string` | Отступ от нижнего края экрана | `"120px"`, `"10vh"` |
| `left` | `string` | Отступ от левого края экрана | `"15px"`, `"5%"` |

> Осторожно
>
> Рекомендуется указывать не более двух сторон одновременно (например, `bottom` + `right` или `top` + `left`).

### Допустимые значения

Любые валидные CSS-единицы: `px`, `rem`, `vh`, `vw`, `%`.

## Определение окружения

| Условие | Значение `env` |
| --- | --- |
| Хост содержит `rc` | `rc` |
| Хост содержит `stable` | `stable` |
| Хост содержит `cdn` | `prod` |
| Иначе | `dev` |

## Шина событий

После инициализации в `window` доступен объект `__WAGERCRAFT_EVENT_BUS__`.

### Доступные события

| Тип события | Назначение | Payload |
| --- | --- | --- |
| `wagercraft:update-position` | Обновление позиции виджета | `{ position: WagercraftPosition }` |

> Заметка
>
> На данный момент это единственное документированное событие для взаимодействия с виджетом. Мы уведомим вас, если появятся новые.

## Глобальные объекты

| Объект | Доступен после | Методы |
| --- | --- | --- |
| `window.MyWidgetLauncher` | Загрузки скрипта | `init()`, `destroy()` |
| `window.__WAGERCRAFT_EVENT_BUS__` | Инициализации виджета | `publish()` |

## Требования к реализации

> Обработка ошибок
>
> Ошибки загрузки и инициализации виджета не должны блокировать основной функционал игры.

> Позиционирование
>
> Позиция виджета не должна перекрывать критичные элементы UI: кнопку спина, меню, панель ставок.

> Окружение
>
> Значение `env` должно соответствовать текущему деплою. Неправильное окружение приводит к ошибкам авторизации. `demo` для Artube Dev и `prod` для Artube Prod.

> Адаптивность
>
> При смене ориентации экрана (portrait ↔ landscape) необходимо пересчитывать и отправлять новую позицию виджета.
