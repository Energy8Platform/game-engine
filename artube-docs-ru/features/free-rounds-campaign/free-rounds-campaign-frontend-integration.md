# Интеграция Free Round Campaign (FRC)

## Введение

Free Round Campaign (FRC) - механизм предоставления игрокам бесплатных спинов с фиксированной ставкой. Кампания имеет ограниченный срок действия и заданное количество раундов.

> Совет
>
> Все данные о состоянии кампании приходят от сервера. Клиент не рассчитывает логику, а лишь визуализирует состояние.

## Жизненный цикл FRC на клиенте

1. **Инициализация (Handshake/Session Start)** При старте сессии сервер присылает объект `freeRoundCampaign`. Если он не `null`, значит для игрока есть активная или ожидающая кампания.
2. **Анонсер (Announcer)** Если кампания доступна, клиент должен показать приветственное окно. Согласно требованиям UX, существует два типа отображения в зависимости от настроек кампании:

   - **Type 1 (С таймером):** Отображает кол-во спинов и дату сгорания («Успейте сыграть до…»).
   - **Type 2 (Без таймера):** Отображает только количество спинов.
3. **Режим Free Rounds** После нажатия “Start” игроком:

   - Блокируется выбор ставки (UI установки ставки становится неактивным).
   - Устанавливается `bet`, пришедший в объекте кампании.
   - Отображается счетчик `roundsLeft` / `roundsTotal`.
4. **Геймплей** Спины проходят как обычно. В каждом ответе сервера обновляются счетчики `roundsLeft` и `totalWin`.
5. **Завершение** Когда `roundsLeft` достигает 0:

   - Показывается попап с итоговым выигрышем (`totalWin`).
   - Интерфейс разблокируется, возвращаясь к дефолтной ставке игрока.

## Данные кампании

### FreeRoundCampaign

Объект с информацией о кампании бесплатных раундов:

```plaintext
FreeRoundCampaign {
  campaign_id: string      // Уникальный идентификатор кампании
  bet: number             // Фиксированная ставка для бесплатных раундов
  rounds_total: number     // Общее количество бесплатных раундов
  rounds_left: number      // Оставшееся количество раундов
  total_win: number        // Накопленный выигрыш за кампанию
  valid_from: string       // Дата начала действия (ISO 8601)
  valid_to: string         // Дата окончания действия (ISO 8601)
  is_complete: boolean     // Флаг завершения кампании
}
```

| Поле | Тип | Описание |
| --- | --- | --- |
| `campaign_id` | `string` | Уникальный идентификатор кампании (UUID) |
| `bet` | `number` | Ставка, на которой будут проводиться бесплатные раунды |
| `rounds_total` | `number` | Сколько всего раундов предоставлено |
| `rounds_left` | `number` | Сколько раундов осталось отыграть |
| `total_win` | `number` | Сумма выигрышей за все сыгранные раунды кампании |
| `valid_from` | `string` | Начало периода, когда кампанию можно активировать |
| `valid_to` | `string` | Конец периода, после которого кампания сгорает (ISO 8601, UTC) |
| `is_complete` | `boolean` | `true` когда все раунды отыграны или кампания отменена |

> Осторожно
>
> Поле `freeRoundCampaign` может быть `null` - это означает отсутствие доступных кампаний.

## Запросы API

Вам необходимо самостоятельно интегрировать запрос активации кампании в клиент-серверное общение игры. Сервер, в свою очередь, будет общаться с Artube Games API.

### Обновление данных

Данные о кампании должны обновляться автоматически:

- В ответе на каждый спин
- В ответе на запрос сессии при переподключении

Artube Games API предоставляет всю необходимую актуальную информацию, вам лишь необходимо верно отобразить её игроку.

## Состояния кампании

| Состояние | Условие | Действие |
| --- | --- | --- |
| Доступна | `free_round_campaign !== null && !is_complete` | Показать предложение активации |
| Активна | `is_frc_active === true && rounds_left > 0` | Заблокировать смену ставки, проводить спины |
| Завершена | `is_complete === true \|\| rounds_left === 0` | Показать итоги, вернуть обычный режим |
| Отсутствует | `free_round_campaign === null` | Обычный режим игры |

## Логика обработки ставки

1. **При активации FRC**

   Найти индекс ставки `bet` из ответа в массиве `allowed_bets`. Установить эту ставку как текущую.
2. **Во время FRC**

   Заблокировать UI изменения ставки. Все спины проводятся на фиксированной ставке.
3. **После завершения FRC**

   Разблокировать UI ставки. Вернуть предыдущую ставку игрока или оставить текущую.

> Заметка
>
> Если ставка из FRC отсутствует в `allowed_bets` - это ошибочная ситуация. Кампания не должна активироваться.

## Обработка ошибок

| Ситуация | Поведение |
| --- | --- |
| Кампания не найдена | Скрыть UI активации, продолжить обычную игру |
| Кампания уже активирована | Игнорировать повторную активацию |
| Кампания истекла | Скрыть предложение, очистить данные FRC |
| Недостаточно средств (обычный спин во время FRC) | Невозможно - FRC спины бесплатны |
| Потеря соединения во время FRC | При реконнекте восстановить состояние из сессии |

> Критическая фаза
>
> Реконнект во время активного FRC считается критической фазой. Необходимо корректно восстановить состояние кампании из ответа сессии.

## Требования к UI

> Предложение активации
>
> Показывать модальное окно или баннер с информацией: количество бесплатных раундов, размер ставки, срок действия. В Artube UI оно уже предусмотрено.

> Прогресс
>
> Во время FRC отображать счётчик оставшихся раундов. В Artube UI он уже предусмотрен.

> Завершение
>
> По окончании кампании показать итоговый экран с общим выигрышем перед возвратом к обычной игре. В Artube UI он уже предусмотрен. Если кампания завершилась из-за истечения срока, также показать уведомление с общим выигрышем.

> Блокировка ставки
>
> Визуально обозначить, что ставка заблокирована. В Artube UI это уже предусмотрено.

## Взаимодействие с другими системами

| Система | Поведение во время FRC |
| --- | --- |
| Autoplay | Работает на фиксированной ставке |
| Buy Bonus | Недоступен во время FRC |
| Баланс | Не списывается за спины |
