# Общая информация

## Обзор разработки игр

Разработка игр для платформы Artube включает создание как клиентской части (frontend), так и серверной логики (backend) с интеграцией через Artube Games API.

## Технологические стеки

### Frontend стек

- **TypeScript** - основной язык разработки
- **Preact** - Artube UI
- **PIXI.js** - для 2D графики в Canvas (вы можете использовать другие библиотеки и движки)

### Backend стек

- Сервер может быть реализован на любом языке программирования
- Вы должны обернуть написанное в Dockerfile (в корне репозитория)

Требования к деплою бэкенда (Dockerfile, порт, переменные окружения, CI/CD, health-пробы, формат логов) собраны на странице **[DevOps и деплой бэкенда](../game-development/devops.md)**.

## Архитектурные подходы

- Клиент отображает данные, полученные от сервера, с минимальными изменениями — его задача лишь в воспроизведении раунда с использованием различных анимаций
- Клиент может предоставлять выбор во время раунда для Gamble и других интерактивных механик
- Сервер игры выполняет расчёт раунда. Он должен быть stateless и хранить состояние в Artube Games API

## Локализация и языки

Платформа Artube поддерживает несколько языков интерфейса. При запросе языка, который не поддерживается игрой или платформой, автоматически применяется **фолбэк на английский (`en`)**.

> Заметка
>
> Если запрошенный язык недоступен — игра отображается на английском языке. Убедитесь, что ваша игра корректно обрабатывает этот сценарий и предоставляет английский контент как запасной вариант.
