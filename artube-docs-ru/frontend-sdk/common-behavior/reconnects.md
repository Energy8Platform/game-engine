# Базовый сценарий переподключения

Эта страница описывает **механизм переподключения**. Он предназначен для автоматического восстановления игровой сессии при потере сетевого соединения или при переразвёртывании подов.

## Обзор

Игра продолжается без перезагрузки, где это возможно. Система пытается прозрачно восстановить соединение WebSocket и автоматически выполняет восстановление сессии.

> Осторожно
>
> **Клиент не должен обрывать WebSocket-соединение принудительно.** При потере соединения клиент инициирует переподключение — не закрывает соединение со своей стороны. Соединение удерживается клиентом до получения явного сигнала от сервера (например, [`GoAway`](../../games-api-integration/control-requests/goaway.md)).

## Поведение

- Выполняется до **5 попыток переподключения**.
- При **успешном подключении**:

   - Если есть незавершённые запросы → отправляется запрос `session` для получения данных сессии, после чего выполняются отложенные запросы.
   - Если незавершённых запросов нет → игра получает уведомление о восстановлении соединения.
- При ошибке:

   - Отображается модальное окно с сообщением об ошибке и возможностью перезагрузки.

## Визуальная обработка

- Во время переподключения отображается индикатор загрузки.
- Индикатор загрузки блокирует клики мышью, но не пробел → в критических режимах (например, при запуске бонусных раундов) игру необходимо вручную настроить на блокировку пробела.
- Если переподключение не удалось, отображается всплывающее окно с ошибкой.

## Специальный случай: запрос на спин

Если отключение происходит после запроса на спин, но до получения ответа:

- Запрос на спин помечается как `Переподключённый`.
- Данные сессии определяют, что отображается:

   - Если запрос не дошёл до сервера → восстановить последний баланс/ставку, сбросить выигрыши.
   - Если запрос был обработан на стороне сервера → показать результат вращения барабанов и начислить выигрыши.

## Наилучшее применение

Выберите этот подход, если:

- В вашей игре отсутствуют сложные критические фазы.
- Для работы хватает минимальной настройки и автоматического восстановления.
- Нужен единый и простой механизм переподключения.
