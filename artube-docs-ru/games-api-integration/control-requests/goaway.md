# GoAway

## Обзор

Сообщение `GoAway` - это уведомление от сервера клиенту о том, что соединение будет корректно закрыто. Это позволяет клиенту корректно завершить текущие операции и подготовиться к переподключению.

> Осторожно
>
> **Клиент не должен обрывать WebSocket-соединение самостоятельно.** При получении `GoAway` клиент должен корректно завершить текущие операции и дождаться закрытия соединения со стороны сервера, после чего инициировать переподключение согласно значению `retry_after_ms`.

     Protocol `1`   Schema `1`   Channel `control`   Type `GoAway`   Timestamp 1/1/2023, 12:00:00 AM        Message ID `goaway-notification-id`    Operation Sequence 100
#### Payload

```
{
  "reason": "Server shutdown for maintenance",
  "retry_after_ms": 30000
}
```

## Структура сообщения

### Поля сообщения

| Поле | Тип | Обязательность | Описание |
| --- | --- | --- | --- |
| `reason` | string | обязательное | Причина закрытия соединения |
| `retry_after_ms` | int | обязательное | Время до рекомендуемого переподключения в мс |

## Типы причин GoAway

### Плановые отключения

#### Техническое обслуживание

```json
{
  "reason": "Server shutdown for maintenance",
  "retry_after_ms": 1800000
}
```

#### Обновление сервера

```json
{
  "reason": "Server update in progress",
  "retry_after_ms": 300000
}
```

### Аварийные отключения

#### Перегрузка сервера

```json
{
  "reason": "Server overload",
  "retry_after_ms": 60000
}
```

### Административные действия

> Осторожно
>
> Всегда обрабатывайте GoAway сообщения gracefully. Игнорирование этих сообщений может привести к потере данных игрока.
