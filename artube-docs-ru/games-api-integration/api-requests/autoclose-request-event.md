# AutocloseRequestEvent

## Обзор

Событие `AutocloseRequestEvent` отправляется сервером клиенту для необходимости доигрывания и закрытии раунда. Это может произойти, например, когда игрок был неактивен в течение определенного периода времени или когда игра, исходя из своей внутренней логики, определяет, что раунд должен быть завершен. Цель этого события — уведомить клиента (бэкенд игры) о необходимости завершения текущего раунда и соответствующего обновления баланса игрока. Клиент должен ответить на это событие, отправив запрос `AutocloseRoundRequest` с окончательным состоянием раунда, включая итоговый множитель выигрыша, статус и любые активированные функции. Правильная обработка этого события имеет решающее значение для обеспечения бесперебойной работы игры и предотвращения проблем, связанных с неактивными сессиями или незавершенными раундами.

## Событие от сервера

     Protocol `1`   Schema `1`   Channel `events`   Type `AutocloseRequestEvent`   Timestamp 1/1/2023, 12:00:00 AM        Message ID `01234567-89ab-cdef-0123-456789abcdef`    Operation Sequence 102
#### Payload

```
{
  "session_id": "12345678-1234-5678-9abc-123456789012",
  "round_id": "12345678-1234-5678-9abc-123456789012",
  "round_version": 1,
  "round_state_version": "v1",
  "round_state": "{\"step\": 4, \"final_result\": \"completed\", \"total_win_multiplier\": 4.00}",
  "currency_minimal_unit": 0.01
}
```

### Поля события

| Поле | Тип | Обязательность | Описание |
| --- | --- | --- | --- |
| `session_id` | string | обязательное | ID сессии (GUID) |
| `round_id` | string | обязательное | ID раунда (GUID) |
| `round_version` | number | обязательное | Версия раунда |
| `round_state_version` | string | обязательное | Версия состояния раунда |
| `round_state` | string | обязательное | Состояние раунда в формате JSON |
| `currency_minimal_unit` | decimal | обязательное | Минимальная единица валюты, в которой начат раунд |

## Пример обработки

**Обработка события изменения состояния раунда:**

- Извлечение нового состояния раунда из payload
- Доигрывание раунда от лица игрока, если это предусмотрено логикой игры
- Отправлениме запроса на закрытие раунда с новым состоянием через **AutocloseRoundRequest**
