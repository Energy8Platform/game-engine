# NewConnectionEvent

## Обзор

`NewConnectionEvent` Уведомление об открытии нового соединения между игроком и игровым сервером.

## Назначение

Событие `NewConnectionEvent` отправляется сервером клиенту при открытии нового соединения между игроком и игровым сервером. Это может произойти, например, при открытии новой вкладки с игрой. Цель события — информировать клиента о новом соединении, чтобы он мог обновить свои данные о сессии и обеспечить корректную работу игры. Клиент должен сравнить ID нового соединения с текущим активным соединением и, если они не совпадают, закрыть старое соединение. Обработка этого события важна для поддержания стабильного соединения и предотвращения конфликтов между несколькими активными соединениями, что может привести к некорректной работе игры, но обработка этого события опциональна и зависит от самой игры.

> Осторожно
>
> В `stateless` играх данная обработка не требуется.

## Событие от сервера

     Protocol `1`   Schema `1`   Channel `events`   Type `NewConnectionEvent`   Timestamp 1/1/2023, 12:00:00 AM        Message ID `01234567-89ab-cdef-0123-456789abcdef`    Operation Sequence 102
#### Payload

```
{
  "session_id": "12345678-1234-5678-9abc-123456789012",
  "new_connection_id": "12345678-1234-5678-9abc-123456789012"
}
```

### Поля события

| Поле | Тип | Обязательность | Описание |
| --- | --- | --- | --- |
| `session_id` | string | обязательное | ID сессии (GUID) |
| `new_connection_id` | string | обязательное | ID нового соединения (GUID) |

## Пример обработки

**Обработка события нового соединения:**

- Извлечение ID нового соединения из payload
- Сравнение с текущим активным соединением между фронтендом и сервером игры, если не совпадает, закрыть текущее соединение
