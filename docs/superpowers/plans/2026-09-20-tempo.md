# Tempo Implementation Plan (slice 25)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A real tumble (gravity + refill) as a step the reels board plays through the legacy `TumbleController`, a turbo flag and a skip carried from the page through the flow to the board, and sound categories with fades — so a cascade game looks and paces like one.

**Architecture:** `TumbleStep` joins the vocabulary; `ReelsBoard.tumble` maps it onto `ReelSystem.cascade`; `mechanic-cascade` emits it under a `tumble` config. `execute(plan, board, registry, { turbo })` threads `StepOpts` to the board/handlers; `PlayService.skip()` collapses the board; the play-loop row listens for `ui.skip` on the flow bus; `present.turbo` reads a run var the page seeds through `ui.spin`'s payload. `fx1` keeps category volumes and per-instance ramps; an `audio` kind sets a category.

**Tech Stack:** `@energy8platform/game-engine/slot` (`ReelSystem.cascade/skip`, `StepRunOpts`, `TumbleStep`), `@pixi/sound` 6, cordis 4, schemastery, vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-09-20-tempo-design.md`

## Global Constraints

- `TumbleStep { kind: 'tumble'; winning: Cell[]; removed: Cell[]; drops?: {col,fromRow,toRow}[]; fresh: {col,row,symbol}[]; settled: Board }`; `KNOWN_STEP_KINDS` + `isPresentationStep` updated; `StepOpts { turbo?: boolean }`.
- `BoardApi` methods take `opts?: StepOpts`; `BoardApi.tumble(step, opts?)`; `ReelsBoard.skip()` → `reelSystem.skip()`; `ReelsBoard.config` read-only; `tumble` → `reelSystem.cascade([mapped], { turbo })`, re-sync `reelSystem.board` after, `bindAll()`.
- `PlayService.execute(plan, board, registry?, opts?)` forwards to the board and handlers; `PlayService.skip()` → `board.skip?.()` + every registered handler's `skip?.()`; the play-loop row subscribes to `ui.skip` on the flow bus (lenient) → `skip()`; `StepHandler.skip?()`.
- `mechanic-cascade` config `tumble: boolean` default `false`; `true` → per round ONE `tumble` (`winning = removed`, `settled = round.grid`, `fresh` = per column the top `k` cells of `settled`, `k` = removed cells in that column) + `revealWins` when the round wins; `spinTo` unchanged; `schema.ts` carries `tumble`.
- `present.turbo`: `string` default `'$turbo'`; `'true'`/`'false'` literal or a `$path`; absent var → `false`; passed as `execute`'s `{ turbo }`.
- `sound` gains `category` (`sfx|music`, default `sfx`), `fade` (ms, default 0); `audio { category, volume: string default '1', fade }` sets the category volume (0..1) and ramps live instances; `outs: ['next']`; ramps on an injectable clock.
- Example ≡ template: `index.html` `#turbo` checkbox; `main.ts` emits `ui.spin { turbo }`, a click while `flow.busy()` emits `ui.skip`, hooks `spin({ turbo? })`, `skip()`, `lastStepOpts()`; `flow.yml` `mode` (`set turbo = '$event.payload.turbo'`, ui 490/240) between `idle` and `click`; pins hold.
