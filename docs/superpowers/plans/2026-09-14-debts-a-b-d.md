# Debts A, B, D — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pay the recorded debts of slices 5–9 that are visible to a user (dead `e8-server` shown as live, `Cmd+S` dialogs, stuck tabs, a false "connecting…"), give the one diagnostics list a retract on both sides, and make the UI one language with one formatter.

**Architecture:** No wire change. The host's own diagnostics become groups keyed by speaker (`reportGameDiagnostics(speaker, list)` replaces a group); the client's `connection.report(d)` returns a retract. `session-dev` learns that its process died (`E8Handle.onExit`) and says so with a code the status bar reads. Shell/App/Projects/Explorer get the four small behaviours. Everything user-facing becomes English by a fixed dictionary; prettier runs once, alone.

**Tech Stack:** cordis 4.0.0-rc.8, Vitest, Playwright, React 18, prettier.

**Spec:** `docs/superpowers/specs/2026-09-14-debts-a-b-d-design.md`

## Global Constraints

- `Diagnostic` and `ServerMessage` do NOT change (spec §2 B1).
- Host list = groups by speaker; `reportGameDiagnostics(speaker, list)` replaces that group only; the frame carries the whole list; an empty list removes the group. Speakers used: `'session'` (restart, exit), `'spin'` (`/api/spin`), `'dev-game'` (preview bind, unusable spec).
- Client `report(d)` returns `() => void`; retract by identity of the stored entry; twice is a no-op.
- `SessionStatus` reads `code` (`'exited'`, `'restarting'`), never prose.
- Every string a user sees is English (spec §3 dictionary, verbatim). Diagnostics stay as they are (already English).
- Prettier: one commit, formatting only, no other change in it.
- Every assertion with a mutation confirmed LANDED by before/after count on the ORIGINAL file.
- Playwright ALONE of every root-level npm command; `pgrep -fl e8-server` before/after; 5679/5680/5681; no `e8-compose-*` left.
- Shell is zsh: no trailing `#` comments. Nothing under `packages/` staged.

  - the reset on project leaving (slice 9) still clears everything (existing test stays green).

- [ ] **Step 2: Implement** — `const groups = new Map<string, DiagnosticsService>()`; `reportGameDiagnostics(speaker, list) { if (!list.length) groups.delete(speaker); else { const g = createDiagnostics(); for (const d of list) g.report(d); groups.set(speaker, g); } frame = { diagnostics: [...groups.values()].flatMap(g => [...g.list()]), dropped: sum }; … }`.
