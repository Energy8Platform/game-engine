# BAD MANNERS — брендбук и ТЗ обвязки слота

> Документ — исполняемая спецификация для Claude Code. Всё, что нужно для реализации, лежит рядом в `brand-kit/`. Где документ и макет расходятся — прав документ; макеты в `mockups/` задают настроение и композицию, а не пиксели.

Стек: PixiJS v8 + React (оверлеи по желанию), `@energy8platform/game-engine`. Документ не завязан на API движка: компоненты описаны как Pixi-контейнеры; встраивай их через существующий жизненный цикл сцен и слой оверлеев движка, ничего не дублируя.

---

## 0. Как работать с этим документом (для Claude Code)

1. Прочитай §1–§3 целиком, остальное — по мере реализации.
2. Порядок работ: §8 «План реализации». Каждый шаг заканчивается проверкой из §10.
3. Ассеты **не перерисовывать кодом** (`Graphics`) — брать готовые SVG/PNG из кита. Код только раскладывает, красит тинтом и анимирует. Причина: ручная отрисовка выглядит дешевле макетов, бренд держится на «рубленой» форме из кита.
4. Если чего-то не хватает (иконки, плашки) — не выдумывай стиль, а сообщи и используй ближайший примитив из кита.

## 1. Бренд в двух словах

**BAD MANNERS** — дерзкая, смешная, «невоспитанная» студия. Голос: подмигивает, показывает язык, ругается значками `!@#$`. Визуально — **плоский минимализм**: чёрный, белый и один кислотный лайм. Никаких градиентов, бликов, теней, металла, 3D. Комикс-пузыри вместо прямоугольных панелей.

Три правила, на которых держится всё:

1. **Каждая плашка — речевой пузырь** с хвостиком (заголовки, поля, вкладки, «закрыть»). Кнопки-действия — капсулы-пилюли без хвоста.
2. **Лайм = действие или активное состояние.** Всё остальное — чёрное, белое или серое. Лайм не используется для декора.
3. **Слова — рубленым шрифтом капсом**, цифры — жирным гротеском.

## 3. Основа

### 3.1 Цвет (`tokens.json → color`)

| Токен | HEX | Где |
|---|---|---|
| `ink` | `#0B0B0B` | все плашки, пузыри, карточки |
| `void` | `#000000` | фон интро |
| `paper` | `#FFFFFF` | глифы, заголовки, значения |
| `lime` | `#B6FF3B` | primary-кнопки, активные вкладки и тогглы, лейблы полей, обводки заголовков, прогресс |
| `limeHover` | `#C8FF6A` | hover primary |
| `limePress` | `#8FD61F` | pressed primary, крутящийся SPIN |
| `grey700` | `#2B2B2B` | disabled-плашки, выключенная волатильность |
| `grey600` | `#3A3A3A` | трек прогресса/подчёркивания |
| `grey500` | `#6B6B6B` | disabled-глиф и текст |
| `grey400` | `#8A8A8A` | подписи, счётчики в таблицах |
| `scrim` | `rgba(0,0,0,.55)` | затемнение под панелями (поверх блюра игры 12) |

Запрещено: другие акценты (красный, золото, градиенты). Ошибки — тем же языком: белая обводка + `!@#$`.

### 3.2 Шрифты

| Роль | Шрифт | Правило |
|---|---|---|
| display | **Luckiest Guy** 400 | только КАПС; заголовки, кнопки, лейблы `BALANCE / WIN / BET`, вкладки, названия бонусов |
| numeric | **Montserrat 800** | деньги, множители, счётчики, RTP |
| body | **Montserrat 600** | описания, правила |

Luckiest Guy — только латиница. Для локалей с кириллицей/CJK/арабским display-текст рендерить **Montserrat 900 капсом** (`font.displayFallbackNonLatin`). Выбор шрифта — по локали, не по символам.

Pixi: для HUD-цифр, которые меняются каждый кадр (баланс, счётчик выигрыша), — `BitmapText` (сгенерировать BitmapFont из Montserrat 800 при загрузке, символы `0-9 $€.,×x+-%`). Остальное — `Text` с загруженными через `Assets` webfont.

Размеры — `tokens.json → type` (в дизайн-пикселях 1920×1080).

### 3.3 Форма

- **Пузырь** (`ui/bubble-*`): тело со скруглением 12, хвост 16 px вниз. Хвост слева (`-taill`) или справа (`-tailr`).
  - Хвост **влево**: заголовки панелей, вкладки, поля в левой половине экрана.
  - Хвост **вправо**: «закрыть», поля в правой половине (BET).
  - Контент центрируется в теле, **без учёта хвоста**: тело занимает верхние `H − 16` px.
- **Пилюля** (`ui/pill-*`): капсула r = h/2, без хвоста. Только действия: BUY, ACTIVATE, START, CONFIRM, тогглы HUD.
- **Обводка** 3 px — только у заголовков панелей (лайм), «закрыть» (лайм) и secondary-кнопок (белая/лайм).
- Карточки (Buy Bonus) — прямоугольник `ink` со скруглением 6, без обводки.

### 3.4 9-slice

| Текстура | w×h | left | right | top | bottom |
|---|---|---|---|---|---|
| `bubble-*-taill` | 100×76 | 38 | 22 | 18 | 30 |
| `bubble-*-tailr` | 100×76 | 22 | 38 | 18 | 30 |
| `pill-*` | 68×52 | 26 | 26 | 25 | 25 |
| `slider-track`, `slider-fill` | 32×16 | 8 | 8 | 0 | 0 |
| `underline` | 32×10 | 4 | 4 | 0 | 0 |

Значения в единицах @1x (Pixi сам учитывает `@2x` по `meta.scale`). Минимальная высота пузыря — 56, пилюли — 48. Пилюлю по высоте не тянуть: менять только ширину, высота = 52·k целиком через `scale`.

Варианты пузырей: `bubble-ink`, `bubble-ink-outline` (лайм), `bubble-ink-outline-white`, `bubble-lime`, `bubble-grey`. Пилюли: `pill-lime`, `pill-lime-hover`, `pill-lime-press`, `pill-grey`, `pill-ink`, `pill-ink-outline` (лайм), `pill-ink-outline-white`.

### 3.5 Иконки

37 глифов, нарисованы генерацией (Layer) в стиле вордмарка и оттрейсены в SVG: белая заливка, жирный вес, «рубленые» неровные края — так задумано, не выравнивать. Исходники — `icons/source/` (листы 3×3 и PNG 256×256 с альфой); если глиф перерисовывается вручную, сохранять имя и сетку 64×64 с тем же полем (~8% с каждой стороны). Красятся только `tint`:

| Состояние | Плашка | Тинт глифа |
|---|---|---|
| default | `ink` | `paper` |
| hover / активный тоггл | `ink` (+ лайм-обводка у тоггла) | `lime` |
| pressed | как default, scale .94 | — |
| disabled | `grey700` | `grey500` |
| на лайме (SPIN, primary) | `lime` | `ink` |

Список:
- бренд: `face` — монохромная рожица с языком для тинта (кнопка студии в HUD, мелкие места, ручка слайдера в одноцветном варианте). Цветная версия с лаймовым языком — `logo/bm-mark-face.svg`, её не тинтовать.
- HUD: `menu spin turbo autoplay stop plus minus close info`
- навигация и звук: `rules back chevron-left chevron-right check sound-on sound-off music music-off`
- сервисные: `history replay fullscreen home buy history-list settings lock trophy`
- грауликс и «ругательства»: `grawlix-excl grawlix-at grawlix-hash grawlix-dollar grawlix-percent grawlix-asterisk skull bomb spiral` (skull/bomb/spiral — для пузырей ошибок, крупных выигрышей, декора текста; не для кнопок)

Размер текстуры глифа внутри плашки ≈ 55–60% стороны плашки (76 → 44).

### 3.6 Лого

- Основной — `bm-logo-horizontal`. Стек — для интро и промо. Знак-рожица — для мест < 120 px.
- У SVG есть чёрная «подложка» (`#backer`) — она даёт наклеечную обводку и делает лого читаемым на любом фоне. Не удалять.
- Подчёркивание: лайм ≈ 70%, серый остаток. В интро оно же — прогресс загрузки.
- Не перекрашивать, не вращать, не обводить, не класть на лайм. Охранное поле — высота буквы `B`.

### 3.7 Волатильность — «грауликс»

Пять глифов подряд: `!` `@` `#` `$` `%` (`icon/grawlix-*`). Уровень N из 5 = первые N лайм, остальные `grey700`. Шаг 8 px, размер глифа 38. Подписи уровней (если нужны): `LOW / MEDIUM / HIGH / VERY HIGH / INSANE`.

## 4. Компоненты

Реализовать в `src/ui/bm/` (или в принятой в проекте папке темы). Все размеры — дизайн-пиксели 1920×1080.

### 4.1 `Bubble`
```ts
type BubbleVariant = 'ink' | 'ink-outline' | 'ink-outline-white' | 'lime' | 'grey';
new Bubble({ variant, tail: 'l' | 'r', width, height, content?: Container });
```
`NineSliceSprite` из `ui/bubble-<variant>-tail<l|r>` + контейнер контента, центрированный в теле (`H − 16`). Метод `pop()` — появление из точки хвоста (`motion.bubblePop`).

### 4.2 `PillButton`
```ts
new PillButton({ label, kind: 'primary' | 'secondary' | 'secondary-white', width = 300, height = 64 });
```
- primary: `pill-lime`, текст `ink`; hover → `pill-lime-hover`; pressed → `pill-lime-press` + y+2, scale .97; disabled → `pill-grey`, текст `grey500`.
- secondary: `pill-ink-outline` (лайм), текст `paper`; secondary-white: `pill-ink-outline-white`.
- Меняется **текстура**, а не тинт: так цвета точно совпадают с токенами.
- Hit area = прямоугольник кнопки + 8 px по краям; минимум 64×64 на мобиле.

### 4.3 `IconButton`
```ts
new IconButton({ icon: 'menu', shape: 'bubble-l' | 'bubble-r' | 'pill' | 'square', size = 76, toggle?: boolean });
```
Плашка (`bubble-ink`, `pill-ink`, при `toggle && on` — `pill-ink-outline`) + глиф 64×64, отмасштабированный до ≈ 0.55·size. Состояния — по таблице §3.5.

### 4.4 `Field` (BALANCE / WIN / BET)
Пузырь `bubble-ink` высотой 76. Внутри: лейбл display 24 `lime` + отступ 12 + значение numeric 28 `paper`. Ширина подстраивается под значение, но не меньше 220; растёт только вправо (у `tail: 'r'` — влево), чтобы не дрожать при смене цифр. Для BET: `[minus] BET $1.00 [plus]`, глифы ± тинтом `lime` 26 px, каждый со своей hit area 64×64.

### 4.5 `SpinButton`
- База `ui/spin-base` (128×128: чёрное кольцо + лаймовый диск) + глиф `icon/spin` тинт `ink`, 66 px.
- Состояния: idle (`spin-base`), hover (`spin-base-hover`), pressed (`spin-base-press`, scale .94), spinning (`spin-base-press`, глиф крутится 2.2 об/с, в turbo — 4), disabled (`spin-base-disabled`, глиф `grey500`).
- Во время раунда, если остановка разрешена: глиф `stop` 44 px.
- Автоплей: вместо глифа — число оставшихся спинов, display 46 `ink`; тап = стоп автоплея.

### 4.6 `Slider` (ставка, автоплей, громкость)
- Трек: `slider-track` 9-slice, высота 16, `ink`. Заливка: `slider-fill` до **центра** ручки.
- Ручка: `logo/bm-mark-face` 62 px, pivot в центре; при перетаскивании scale 1.1 и поворот −8° (возврат `back.out(3)`).
- Значение — пузырь `bubble-ink-outline-taill` над ручкой (хвост указывает на ручку), numeric 22; ездит вместе с ручкой и не выходит за края трека.
- Дискретные шаги (список ставок или `[10,25,50,100,250,500,1000,∞]`) — ручка прилипает к ближайшему шагу.
- В меню громкости значение не показывается.

### 4.7 `Volatility`
Ряд из 5 глифов грауликса (§3.7). Компонент принимает `level: 1..5`.

### 4.8 `PanelFrame` (база для всех оверлеев)
1. Фон: снимок игры с `BlurFilter(12)` + `scrim` (`rgba(0,0,0,.55)`), входит 180 мс.
2. Заголовок: `Bubble ink-outline, tail l`, display 44, слева сверху (x = 48, y = 40), высота 84.
3. «Закрыть»: `IconButton close`, пузырь `ink-outline` с хвостом **вправо**, 88×84, справа сверху (отступ 48/40). `Esc` тоже закрывает.
4. Контент центрирован, max-width 1240.
5. Вход: контент `motion.panelIn`, заголовок и «закрыть» — `bubblePop` с задержкой 60 мс. Выход: `motion.panelOut`.

### 5.7 Выигрыши и состояния

- **Выигрыш в раунде**: `Field WIN` считает сумму вверх (`motion.winCount`), глиф-пузырь ничем не украшается.
- **Крупные выигрыши** — пузырь `bubble-lime` по центру, слово display 96 `ink` + сумма numeric 72 `ink`, вход `bubblePop`, лёгкая тряска 6 px. Уровни по множителю ставки:
  | ×ставки | Слово |
  |---|---|
  | ≥ 15 | `NOT BAD!` |

## 6. Интро студии

Эталон: `intro/intro-reference.html` (открыть в браузере). Данные: `intro/intro.json` — **реализовать по нему, а не по памяти**: сцена, слои, пивоты, таймлайн и правила.

### 6.1 Сцена
- Фон `void` на весь экран. Сцена 1000×820 дизайн-единиц, вписывается в `min(w/1000, h/820) × 0.62` по центру.
- Слои (снизу вверх): `dot`, `manners`, `badClosed`, `bad`, `tongue`, `bubble`, `burst1..3`, `face`, `track`, `progress`. Координаты/размеры/пивоты — `stage.layers`.
- `badClosed` — «BAD» с обычной буквой A (рот закрыт). `bad` — та же надпись с открытым ртом в A, из которого вылезает язык. Подмена мгновенная в момент появления языка — язык перекрывает шов.
- SVG грузить через `Assets` с `resolution` под DPR (минимум 2), чтобы на ретине не мылилось.

### 6.2 Раскадровка (мс)

| t | Что | Звук |
|---|---|---|
| 0–320 | белая точка-курсор появляется, мигает, схлопывается | `tick` |
| 300 | `BAD` (закрытый рот) слэмом: scale 1.35 → .94 → 1, альфа 0 → 1 | `thump` |
| 380 | `MANNERS` тем же слэмом | `thump` |
| 520 | тряска сцены 140 мс (±7 px) | — |
| 800 | подмена на открытый рот; язык: scaleY 0 → 1.25 → .9 → 1 от верхнего пивота | `raspberry` |
| 1000 | язык виляет ±7° → 0 | — |
| 1200 | пузырь `!@#$` выпрыгивает из точки хвоста, scale 0 → 1.15 → 1 | `censor-bleep` |
| 1600 | рожица падает сверху (y −300, rot −12° → 0), `power2.in` | — |
| 1860 | приземление: squash 1.12/.86 → .97/1.04 → 1; три лаймовые черты разлетаются | `boing` |
| 2150 | появляется серый трек подчёркивания | — |
| 2200 | лаймовая заливка до 70% | `whoosh` |
| ≥2400 | дальше заливка = реальный прогресс загрузки | — |

Изинги в `intro.json` записаны именами GSAP (`power3.out`, `back.out(2.2)`, `power2.in`, `power2.inOut`, `none`). Если в проекте нет GSAP — используй твины движка с такими же кривыми; cubic-bezier-аналоги есть в `intro-reference.html` (`EZ`).

### 6.3 Правила
- **Минимум 2400 мс**; если ассеты не загрузились — держим финальный кадр, а заливка подчёркивания показывает реальный прогресс (не откатывается назад, только растёт).
- **Выход**: когда загружено и t ≥ 2400 → сцена scale 1 → 1.04 и альфа → 0 за 250 мс (`power2.in`), затем игра проявляется из чёрного за 300 мс.
- **Skip**: тап/клик/пробел после 500 мс → прыжок к финальному кадру и снятие минимума; если загружено — сразу выход.
- ~~Короткая версия для повторного запуска~~ — убрана (2026-10-25): интро всегда полное, в storage ничего не пишем; вместо неё skip снимает 2400-мс минимум.
- Интро — первая сцена загрузчика: сначала грузим **только** `logo/*` (≈ 60 КБ), потом стартуем интро и параллельно грузим игру.
- Звук играет только если платформа уже разрешила аудио (после жеста пользователя); иначе интро немое.

## 7. Моушен интерфейса

Значения — `tokens.json → motion`.
- Нажатие: scale .94 за 80 мс, отпускание `back.out(3)` 180 мс. Hover (desktop): смена текстуры/тинта за 120 мс.
- Всё, что «говорит» (пузыри), появляется из точки хвоста (`bubblePop`).
- Панели: `panelIn` / `panelOut`; меню — сдвиг слева.
- Счётчики денег — без «прыжков» ширины: моноширинные цифры BitmapText или фиксированная ширина поля на время счёта.
- `prefers-reduced-motion` или настройка платформы → без тряски, squash и вращения глифа SPIN, только альфа.

## 9. Чего не делать

- Не рисовать плашки/иконки через `Graphics` и не «улучшать» неровные края глифов.
- Не использовать лайм для декора, рамок контента, фонов панелей.
- Не писать заголовки строчными (в макетах местами строчные — это ошибка генерации).
- Не добавлять тени, глоу, градиенты на элементы UI (единственный градиент — затемнение под HUD).
- Не класть лого на лайм и не перекрашивать рожицу.
- Не показывать `JACKPOT`/денежные обещания в интро — это экран студии, а не выигрыш.
